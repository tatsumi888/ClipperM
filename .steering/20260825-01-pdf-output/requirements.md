# 要求内容

## 概要

出力形式に PDF を追加し、EPUB と選べるようにする。用途によって最適解が違うため、どちらか一方に寄せない。

## 背景

Send to Kindle が `rendition:layout`（固定レイアウト）を弾くようになり、EPUB では**等倍表示ができなくなった**。Kindle 側が余白を付けて縮小するため、出力解像度でかけたディザリングのドットパターンが潰れる。

2026-08-24 に14個の変種を実機へ送って切り分けた結果:

| 手法 | 結果 |
|---|---|
| `rendition:layout` あり | 配信拒否（ライブラリに現れない） |
| Amazon 独自 `fixed-layout` メタ | 同上 |
| `itemref properties` / SVG ラッパー | 変換は通るが**開けない本**ができる |
| CSS（`@page margin:0` / `!important` / `vw` / `absolute`） | 余白を殺せない。`absolute` は端末の描画が停止する |
| **PDF** | **画面ぴったりに表示された** |

**EPUB でできる手は出尽くしている。** 一方 PDF は変換を挟まずそのまま表示されるため、ページサイズを画像の実寸に合わせれば等倍になる。

## トレードオフ（Kindle 側の仕様なので解消できない）

| | カバー（スリープ画面） | 表示 | ファイルサイズ |
|---|---|---|---|
| EPUB | **○** | 少し小さい（縮小される） | 920KB/ページ |
| PDF | × | **画面ぴったり（等倍）** | **318KB/ページ** |

用途が「読む」と「スリープ画面に出す」で分かれており、どちらを捨てても機能が損なわれる。**両方を出力できるようにして、送るときに選ぶ**のが要求。

## 実装対象の機能

### 1. PDF 出力

- 切り抜いた画像を、実寸そのままのページサイズで PDF にする
- 複数ページ対応（1画像 = 1ページ、リストの順序を保つ）
- グレースケール時は**可逆**で埋め込む（ディザリングのドットを壊さない）
- フルカラー時は JPEG をそのまま埋め込む（再エンコードしない）

### 2. 形式の選択

- 「EPUB」「PDF」を切り替えられる
- 選択を端末に永続化する
- どちらを選んでいるかが送信前に明確に分かる

### 3. 送信

- PDF も Web Share API で共有できる（`application/pdf`）
- 共有が使えない場合のダウンロードフォールバックは EPUB と同じ

## 受け入れ条件

### PDF の構造

- [ ] `%PDF-` で始まり `%%EOF` で終わる
- [ ] **xref のオフセットが実際のオブジェクト位置と一致する**（ずれると読めない PDF になる）
- [ ] `MediaBox` が画像の実寸と一致する
- [ ] ページ数が入力画像の枚数と一致し、順序が保たれる
- [ ] グレースケールは `/DeviceGray` + `/FlateDecode`（可逆）
- [ ] フルカラーは `/DeviceRGB` + `/DCTDecode`（JPEG をそのまま格納）
- [ ] 日本語タイトルが文字化けしない

### 選択と送信

- [ ] EPUB / PDF を切り替えられ、選択が永続化される
- [ ] PDF が共有シートに渡る
- [ ] 共有不可の環境でダウンロードにフォールバックし、その旨が画面に出る

### 非退行

- [ ] 既存の EPUB 出力の挙動が変わらない（65件のテストが通り続ける）

## スコープ外

- PDF のしおり・目次・メタデータ編集
- PDF へのカバー指定（**Kindle が PDF をカバーとして扱わないため、実装しても無意味**）
- 1つの操作で EPUB と PDF を同時に出力すること
