# アーキテクチャ設計スキル

このスキルは、高品質なアーキテクチャ設計書を作成するための詳細ガイドです。

## 前提条件

アーキテクチャ設計を開始する前に、以下を確認してください:

### 必須ドキュメント

**まず `docs/` を一覧してください。** 番号の有無を問わず、以下2種が存在すればよい:

1. PRD(`product-requirements.md` / `01-product-requirements.md` 等)
2. 機能設計書(`functional-design.md` / `02-functional-design.md` 等)

アーキテクチャ設計は、PRDの要件と機能設計を技術的に実現するための
システム構造とテクノロジースタックを定義します。

## 既存ドキュメントの優先順位

**重要**: `docs/` に既存のアーキテクチャ設計書がある場合(ファイル名は `architecture.md` でも
`03-architecture.md` でも構いません)、以下の優先順位に従ってください:

1. **既存のアーキテクチャ設計書** - 最優先
   - プロジェクト固有の技術選定と設計が記載されている
   - このスキルのガイドより優先する
   - **既存のファイル名・パスをそのまま使う。** 番号付きの新名へリネームしない

2. **このスキルのガイド** - 参考資料
   - 汎用的なテンプレートと例
   - 既存設計書がない場合、または補足として使用

**新規作成時**: このスキルのテンプレートとガイドを参照
**更新時**: 既存設計書の構造と内容を維持しながら、既存のファイル名のまま更新する

## 出力先

**まず `docs/` を一覧してください。** 同種のドキュメント(アーキテクチャ設計書)が既にある場合は、
番号の有無やファイル名の違いを問わず、**そのファイルをそのパスのまま更新します**
(新しいファイルを作らない)。

新規作成時は、以下に保存してください:

```
docs/03-architecture.md
```

## テンプレートの参照

アーキテクチャ設計書を作成する際は、次のガイドを参照しながら、テンプレートを使用してください:
- ガイド: ./guide.md
- テンプレート: ./template.md
