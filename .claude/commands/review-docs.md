# ドキュメントレビュー

**引数:** レビュー対象のドキュメントパス (例: `/review-docs docs/01-product-requirements.md`。
既存プロジェクトで番号なしのファイル名を使っている場合はそのパスを渡す)

## 手順

### ステップ1: ドキュメントの存在確認

指定されたドキュメントが存在するか確認します。

### ステップ2: doc-reviewerサブエージェント起動

doc-reviewerサブエージェントを起動してレビューを実施します:

Task toolを使用してdoc-reviewerサブエージェントを起動してください:
- subagent_type: "doc-reviewer"
- description: "Document detailed review"
- prompt: "[ドキュメントパス]を詳細にレビューしてください"

以下の観点で評価してください:
1. 完全性: 必要な項目がすべて含まれているか
2. 具体性: あいまいな表現がないか
3. 一貫性: 他のドキュメントと整合しているか
4. 測定可能性: 成功指標が測定可能か(PRDの場合)

レビューレポートを作成してください。

### ステップ3: レビュー結果の要約

サブエージェントが作成したレビューレポートの要点を抽出し、ユーザーに報告します。

## 出力形式

```markdown
# ドキュメントレビュー結果

## ドキュメント: [ファイル名]

### 主な改善点

1. [改善点1] (優先度: 高/中/低)
2. [改善点2] (優先度: 高/中/低)
3. [改善点3] (優先度: 高/中/低)

### 総合評価

[1-5]/5

### 次アクション

- [推奨対応1]
- [推奨対応2]

詳細なレポートはサブエージェントの出力を参照してください。
```
